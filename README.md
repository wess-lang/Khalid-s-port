# Khalid Makkawi — Portfolio & Case Studies

Live portfolio website for **Khalid Makkawi**, Marketing & Business Development Senior based in Amman, Jordan.

## 🚀 Overview

This repository contains the standalone, high-performance web portfolio featuring:
- **Comprehensive Case Studies**: Lifey × Jordan Breast Cancer Program, Hongqi Automotive Launch, Baby Life Scaling, Sakher Arabi Creative Testing.
- **Field Research & Trade Intelligence Suite**: 6 authentic study documents including Safeway 7th Circle audit, Shini & HyperMax branch analysis, 25+ store inventory audit matrices, sales rep contract compliance & shelf space share tracking, and 4-chain hypermarket competitor price benchmarking (Cozmo, Safeway, Yaser Mall, HyperMax).
- **Paid Media Performance Metrics**: Live Meta Ads Manager data, breakdown of CPC/CPA/CPM pacing.
- **Trade Marketing & Experiential**: Amman Marathon children's race activation, educational health sessions, conference booths.
- **Exhibition Architecture**: Venome modular stand kits (Gold and Clinical Blue skins), Pharma Care detailing stands.
- **Production & Videography**: Executive two-hander rooftop interviews, studio cyclorama direction, commercial lighting.
- **Interactive UI**:
  - 🌓 Dark / Warm editorial theme toggle
  - 🔍 Fullscreen image lightbox modal
  - 📋 One-click copy email & direct WhatsApp trigger
  - 📊 Animated progress indicators and live stat counters
  - 🖨️ Clean print layout formatted for PDF export

## 🌐 Publish & Host Online (Free Live Link)

### Option 1: GitHub Pages (Recommended)
1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/khalid-portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
5. In ~1 minute, your live URL will be active at:
   `https://YOUR_USERNAME.github.io/khalid-portfolio/`

---

### Option 2: Instant Hosting via Vercel or Netlify
- Drag and drop this folder onto [netlify.com/drop](https://app.netlify.com/drop) or import from GitHub on [vercel.com](https://vercel.com).
- You will get an instant live shareable link (e.g. `khalid-portfolio.vercel.app` or `khalid-makkawi.netlify.app`).
